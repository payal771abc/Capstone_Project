# 🌸 Women's Career Recommendation System Using Machine Learning

## 📌 Project Overview

The **Women's Career Recommendation System** is a Machine Learning project designed to recommend suitable career options based on an individual's personal, educational, technical, professional, and work-preference information.

The system analyzes multiple factors such as age, education, degree, skills, technical skills, soft skills, work experience, interests, career interests, personality strengths, preferred work environment, salary expectation, location preference, and work-life balance preference.

The project uses both **Supervised Machine Learning** and **Unsupervised Machine Learning** techniques.

---

## 🎯 Problem Statement

Career selection can be difficult because it depends on multiple factors such as:

- Technical skills
- Soft skills
- Education and degree
- Work experience
- Interests
- Career interests
- Personality and strengths
- Preferred work environment
- Salary expectations
- Location preference
- Work-life balance

Traditional career guidance may provide general suggestions instead of personalized recommendations.

Therefore, this project aims to develop a Machine Learning-based system that can analyze an individual's profile and recommend a suitable career in a personalized and data-driven way.

---

## 🎯 Objectives

- Develop a Machine Learning-based career recommendation system.
- Analyze different user profile characteristics.
- Perform Exploratory Data Analysis (EDA).
- Preprocess numerical, categorical, and multi-label features.
- Train multiple classification algorithms.
- Compare model performance using evaluation metrics.
- Select the best-performing classification model.
- Apply K-Means clustering for unsupervised analysis.
- Provide personalized career recommendations.

---

## 📊 Dataset

The project uses:

**Dataset:** `Womens_Career_Recommendation_Dataset_5000_Balanced.csv`

The dataset contains **5,000 records** and **15 main features/columns**.
